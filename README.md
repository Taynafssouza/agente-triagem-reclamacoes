# Agente de triagem de reclamações

**Problema:** a triagem manual de reclamações de clientes é lenta e inconsistente.

**Solução:** um agente de IA (Claude) que lê a mensagem do cliente, identifica o tipo de problema e a urgência, sugere uma resposta e encaminha ao time certo. Casos sensíveis, como reembolso, vão para uma pessoa.

**Status:** em construção.
